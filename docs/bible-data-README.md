# Persoonlijke Bijbel Data Collectie

Dit is een verzameling open-source Bijbelteksten en data van GitHub, speciaal samengesteld voor een persoonlijke Bijbel-app met focus op Orthodoxe canon, meerdere talen (NL, EN, etc.) en rijke content.

## Inhoud

### midvash-bible-data
- **Bron**: https://github.com/midvash/bible-data
- Schone JSON + SQLite formaten
- Meerdere talen en public domain versies (KJV, ASV, WEB, etc.)
- Goed gestructureerd voor apps

### open-translation-bible
- **Bron**: https://github.com/OpenTranslationBible/open-bible
- Inclusief Nederlands (nl-NL) en vele andere talen
- CC BY-SA

### scrollmapper-bible-databases
- **Bron**: https://github.com/scrollmapper/bible_databases
- Zeer uitgebreide collectie (SQLite, JSON, CSV, etc.)
- Veel versies + cross-references

### modern-brenton-septuagint
- **Bron**: https://github.com/curran-gehring/modern-brenton-septuagint
- Moderne Engelse versie van Brenton's Septuagint (LXX)
- Public domain / CC0
- Ideaal voor Orthodoxe Oude Testament (inclusief deuterocanonieken)

### scrollmapper-deuterocanonical
- **Bron**: https://github.com/scrollmapper/bible_databases_deuterocanonical
- Deuterocanonieke en extra-bijbelse boeken (Tobit, Judit, Wijsheid, Sirach, Makkabeeën, Henoch, etc.)

## Aanbevolen gebruik voor jouw app

1. **Kern data**: Gebruik midvash SQLite of JSON voor snelle start.
2. **Orthodox / Septuagint**: modern-brenton-septuagint + scrollmapper-deuterocanonical.
3. **Nederlands**: open-translation-bible of Statenvertaling (public domain).
4. **Studie**: Cross-references uit scrollmapper.
